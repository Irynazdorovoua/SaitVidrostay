# ВІДРОСТАЙ — оновлений GitHub Pages прототип

## Що всередині
- `index.html` — головна сторінка
- `styles.css` — стилі
- `script.js` — логіка модалок та чекбоксів
- `offer.html` — чернетка публічної оферти
- `privacy.html` — чернетка політики конфіденційності
- `terms.html` — чернетка умов користування
- `contacts.html` — сторінка контактів
- `assets/` — усі фото та логотипи

## Як опублікувати через GitHub Pages
1. Створи новий репозиторій на GitHub.
2. Завантаж УСІ файли з цієї папки разом з `assets/`.
3. Відкрий `Settings → Pages`.
4. Вибери `Deploy from a branch`.
5. Branch: `main`, folder: `/ (root)`.
6. Збережи налаштування.
7. Через 1–3 хвилини сайт з’явиться за посиланням GitHub Pages.

## Важливо перед запуском продажів
Обов’язково заміни:
- email і контакти;
- юридичні дані;
- умови оферти та політики конфіденційності;
- посилання на реальну оплату;
- за потреби тексти CTA і social proof.

## Де міняти кнопку “Отримати”
Поки кнопки ведуть на секцію `#contacts` або `#buy`.
Після підключення оплати можна замінити посилання, наприклад, на:
- сторінку оплати,
- форму,
- Telegram,
- checkout сервісу.
